# Contributing

Use this catalog's issues for broken links, unclear source availability, collection accessibility, and educator-guide suggestions. Report gameplay bugs to the linked source repository when it is available; otherwise include the public play page and the game's title here.

Include the browser/device, steps, expected and observed behavior, and any visible version. Screenshots should exclude identifying information. Never attach credentials, student records, real medical cases, or private browser saves.

For factual corrections, distinguish the game's simplification from the underlying claim and provide an authoritative source. For accessibility reports, describe the barrier and the input or assistive technology involved.

Catalog changes should update `games.json`, regenerate the README, and pass the offline checks. Do not rename or mark repositories transferred until the new destination is verified. Game code and media licensing remain separate; this catalog grants no additional game-asset rights.
